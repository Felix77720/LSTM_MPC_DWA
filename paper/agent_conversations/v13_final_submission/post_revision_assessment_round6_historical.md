## 总体评价

稿件已把研究对象明确为动态障碍物环境中的无人机三维路径规划。它说明了障碍物未来运动难预测为何同时影响 MPC 的长时域路线和 DWA 的短时可达动作筛选，也交代了 LSTM 预测如何以同一时间轴输入两层规划器。48 个混合运动场景、六种预测设置和 864 次匹配运行构成了比此前小规模试验更有力的仿真证据。

预先设定的主要比较显示，共享 LSTM 的目标到达率为 125/144（86.8%），恒速预测为 103/144（71.5%）；配对差为 +15.28 个百分点，按场景聚类的 95% bootstrap CI 为 +6.25 至 +25.69。该区间高于零，支持在本仿真范围内相较 CV 提高目标到达率。相较静态位置预测，成功率差为 +19.44 个百分点（95% CI：+7.64 至 +31.94），最小间隙差为 +0.388 m（95% CI：+0.121 至 +0.666）；这是次要比较，区间未作多重比较校正。

稿件没有把结果扩大成普遍避碰或实机安全结论。它也清楚报告：共享预测与仅 DWA 使用 LSTM 的成功率差为 +2.08 个百分点（95% CI：−1.39 至 +6.94），共享与 CV 的间隙差为 +0.026 m（95% CI：−0.173 至 +0.187）。因此，清楚成立的是相较 CV 的目标到达率提升；尚未成立的是额外把 LSTM 输入 MPC 后优于仅给 DWA 输入的说法，或间隙改善。

## 主要问题

1. **贡献幅度仍须限定。** 论文贡献是预测信息在一个 MPC–DWA 规划器内的集成及其闭环评估。相关模块和预测接口已有先例；当前试验不足以证明相较独立 DWA、独立 MPC 或既有融合规划器的整体优越性。应保持当前较窄的贡献表述。
2. **层间作用未完全识别。** 共享 LSTM 与 DWA-only LSTM 的区间跨零，不能把主要结果归因于“LSTM 注入 MPC”这一单独因素。论文已在摘要、结果、讨论和结论中作此限定。若希望把 MPC 输入预测作为主要创新效果，需要单独设计更有把握的配对消融。
3. **仿真外推受限。** 障碍物按预设轨迹运动且不响应无人机；闭环测试所用运动类型与训练类型重叠；LSTM 输出未校准的不确定性点预测。现有数据不验证未见运动族、真实传感器与动力学误差，也不验证物理飞行安全。
4. **安全语义要保持准确。** MPC 障碍惩罚是软约束；在没有通过安全门的候选动作时，仿真记为不可行并终止。分段线性审计未找到额外状态间碰撞，但这不等于连续物理运动安全保证。

## 结论

**审稿建议：** 若论文将贡献限定为“在固定模拟场景族内，共享 LSTM 预测的集成规划器比同一规划器的 CV 预测设置具有更高目标到达率”，当前实验和稿件能够支撑该仿真论文主张。若要宣称优于独立 DWA/MPC、证明共享预测本身带来安全间隙改善，或推广至未见动态行为和实机飞行，则仍需补充相应基线、泛化和物理验证。投稿时应明确 48 场景来自同一仿真生成分布，且静态基线等次要比较未作多重性校正。
