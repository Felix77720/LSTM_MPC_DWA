# Agent notes and conversation-related records

This is the central folder for manuscript-related AI and agent process records. The Version 13 simulated reviewer reports, review syntheses, self-reviews, and revision checks are grouped in [`v13_final_submission/`](v13_final_submission/). Its README explains the scope and distinguishes these internal records from external peer review.

The other files in this folder hold durable working notes such as evidence reconciliation, reference checks, submission audits, and target-manuscript packaging notes. No raw chat transcript export is present in the paper workspace.
