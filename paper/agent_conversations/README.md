# Agent notes and conversation-related records

This is the central folder for manuscript-related AI and agent process records. The active Version 13 review reports, syntheses, self-reviews, revision checks, and response notes are grouped in [`v13_final_submission/`](v13_final_submission/). Copies of the version-specific review records from Versions 08–12 are grouped in [`historical_versions/`](historical_versions/). The two archive READMEs define their scope and distinguish internal review artifacts from external peer review.

The other files in this folder hold durable working notes such as evidence reconciliation, reference checks, submission audits, and target-manuscript packaging notes. No raw chat transcript export is present in the paper workspace.
