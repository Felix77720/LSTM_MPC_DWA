# Round 6 — 针对 48 场景确认性结果的复审意见

> 本文是编辑完成后的审稿式复核，不冒充新一轮独立、互盲审稿。Round 5 冻结报告未作修改。评审依据为修订稿、实验协议、864 次运行明细、场景簇 bootstrap 输出、补充方法和最终排版 PDF。

## 论文概要

稿件提出一种用于动态障碍环境下无人机三维路径规划的 LSTM–MPC–DWA 集成方法。LSTM 从最近 1 s 的障碍物观测预测 3 s 位置；MPC 在长时域上优化路线，DWA 检查当前可达动作，并把通过筛选的控制范围用于 MPC 的首个控制约束。无人机每执行 0.1 s 后重新规划。

在 48 个混合运动场景、六种预测配置和三个匹配种子下，共运行 864 次。预先设定的主要比较中，共享 LSTM 比恒速预测高 15.28 个百分点目标到达率（95% 场景簇 CI：+6.25 至 +25.69）。这为论文提供了明确且可量化的仿真改进证据。

## 主要意见

### 1. 结果支持一项清楚但范围有限的改进

主要成功率差的场景簇区间完全高于零，抽样单位也按 48 个场景簇处理，没有把同一场景的三个种子误当成独立场景。失败运行保留在分母中。对本文所测试的仿真分布而言，结果支持共享 LSTM 设置优于 CV 预测设置的目标到达率。

作者应继续将此称为**目标到达率提升**。共享 LSTM 与 CV 的间隙差区间跨零，因此不能把主要结果写成安全间隙提升或避碰安全保证。静态位置比较也有正向区间，但属于未作多重比较校正的次要对比。

### 2. 不能把总体提升归因于 MPC 获得了 LSTM 输入

共享 LSTM 与仅 DWA 使用 LSTM 的成功率差为 +2.08 个百分点，95% CI 为 −1.39 至 +6.94；区间不能排除无差异。稿件已避免宣称 MPC 端的 LSTM 注入产生额外提升，这是必要的准确性修正。题目与贡献应继续强调完整规划方法及其相较 CV 的实验证据，不应让读者误以为论文已隔离证明每个模块的增益。

### 3. 比较对象并非独立规划器

六个设置共享同一 MPC–DWA 控制框架，改变的是障碍预测来源或 LSTM 注入位置。实验没有直接对照单独 DWA、单独 MPC，也没有对照控制结构不同的既有 MPC–DWA 系统。因此结果能回答“在该集成控制器内，预测设置改变后表现如何”，不能回答“本文算法整体优于所有传统 DWA/MPC 方法”。引言、摘要及结论当前的限定与证据相符。

### 4. 场景与安全主张尚不能外推到实机

动态障碍轨迹不受无人机影响；闭环运动族与训练类别重叠；模型输出单条点轨迹；仿真不可行分支在无候选通过时结束运行。虽然 864 次试验的线性插值审计没有新增状态间碰撞，仍缺少未见运动族、感知误差校准、硬件闭环和实际飞行证据。摘要与结论中应保留这些范围边界。
